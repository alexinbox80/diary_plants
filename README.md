# Diary Plants

Система автоматизации учета и контроля жизненного цикла растений на базе **Symfony 7**.

## 🏗 Архитектура и проектирование
- **Layered Architecture:** Разделение на контроллеры, сервисный слой и репозитории. Бизнес-логика вынесена в переиспользуемые методы сервисов.
- **Data Integrity:** Строгая типизация свойств, валидация через атрибуты Symfony и использование DTO/моделей для обмена данными между слоями.
- **Database:** Миграции с именованными индексами, внешними ключами и полиморфными связями для хранения изображений (`Attachment`).

## 🔐 Безопасность и документация
- **Гибкая RBAC-модель:** реализована ролевая модель доступа, охватывающая все бизнес-роли проекта, включая уровень глобального администратора.
- **Безопасность на уровне данных:** доступ к контроллерам настроен через компонент Security; внедрены **Voters** для разграничения прав доступа к сущностям на базе идентификаторов групп (Group ID).
- **Надежная аутентификация:** внедрена авторизация через **JWT** с механизмом автоматического обновления (Refresh Token) через выделенное API.
- **Интерактивная документация:** интегрирован **Swagger (NelmioApiDoc)** для автоматической генерации и удобного тестирования CRUD-операций.

## 🧪 Стратегия тестирования
- **Unit-тесты:** Изолированная проверка сложной логики и кастомных ограничений (`Constraints`).
- **Интеграционные тесты:** Контроль корректности маппинга Doctrine и взаимодействия с БД.
- **Функциональные тесты:** Имитация действий пользователя и проверка HTTP-ответов сервера.

## 📦 Инструменты
- **CLI:** Консольные команды для автоматизации рутинных задач.
- **Infrastructure:** Проект развертывается через Docker и управляется с помощью Makefile.
